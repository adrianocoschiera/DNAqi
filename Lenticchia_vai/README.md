# Lenticchia, vai! – I Custodi del DNA

Gioco accessibile: si guida Lenticchia, il cucciolo dei Custodi, con la **voce**
("vai", "ferma", "indietro", "bau") e si salta **urlando**. Ci sono anche i
pulsanti con i simboli CAA.

**Gioca subito dal browser:** apri la pagina GitHub Pages di questo repository
(Chrome o Edge, meglio con le cuffie) e consenti il microfono.

- Il riconoscimento della voce funziona dentro il browser: niente viene
  registrato o inviato.
- La prima volta scarica circa 30 MB (le "orecchie" di Lenticchia, divise in
  `orecchie_1.bin` e `orecchie_2.bin`); poi parte in pochi secondi.

Versione per Android (APK) e per PC: nella sezione **Releases**.
