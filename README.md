# DNAqi

Sistema operativo assistivo per il supporto alle persone con disabilità cognitive e difficoltà comunicative.

## Sito web

Il repository contiene il sito pubblico bilingue di DNAqi, pronto per GitHub Pages.

### Pubblicazione

1. Caricare i file nella radice del repository.
2. Aprire **Settings → Pages**.
3. Selezionare **Deploy from a branch**, branch `main`, cartella `/ (root)`.
4. Salvare e configurare `www.dnaqi.it` nel campo **Custom domain**.
